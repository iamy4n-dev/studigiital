# Transform

Converts a raw Capture into a structured learning Artifact by running an LLM skill pipeline (infer format → generate content → resolve tags).

## Language

**Skill**:
A single LLM pipeline unit with a fixed input schema, prompt template, and structured JSON output.
_Avoid_: pipeline, chain, agent

**Artifact**:
The structured learning output produced by a Skill — a note, flashcard set, or quiz.
_Avoid_: result, output, document

**Draft Artifact**:
An Artifact produced by a Transform that has no Committed tags yet. Ineligible for Review. Shown in the history tab under a separate "needs tags" section with a "Tag me" badge.
_Avoid_: incomplete artifact, untagged artifact, pending artifact

**Derivation**:
A new Artifact created from the source text of an existing Artifact using a different Skill. Tags are inherited from the source Artifact's committed tags, not re-generated by LLM.
_Avoid_: re-run, re-process, regenerate

**Source artifact**:
The Artifact from which a Derivation originates. Its committed tags are propagated to the derived Artifact's suggested tags.
_Avoid_: original, parent

## Relationships

- A **Capture** is the input to exactly one Transform invocation
- A Transform invocation produces exactly one **Artifact**
- A **Derivation** takes an existing **Artifact** as its source and produces a new **Artifact**
- A **Derivation** inherits the **Source artifact**'s committed tags as suggested tags

## Example dialogue

> **Dev:** "When the user clicks 'Make Quiz' on a Note, should we call SuggestTagsSkill?"
> **Domain expert:** "No — that's a Derivation. The quiz inherits the Note's committed tags as suggested tags. We don't re-generate them."
